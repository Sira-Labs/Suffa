# Suffa — Ideas for better learning and the learner space

- Date: 2026-09-23 · Status: proposal for discussion with the teacher · Related:
  `01-product-spec.md`, `docs/didactics.md`, `docs/plan/engagement-plan.md`,
  `docs/plan/content-plan.md`

Scoring: **Value** for learning (★–★★★), **Effort** in story points (≈ 20 pts per sprint).
"Planned" marks ideas already in the roadmap; everything else is new.

## 1. Learn better (didactics)

| Idea                                                                                                                                                                                                                | Value | Effort | Note          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- | ------ | ------------- |
| **More exercise types per word**: cloze in a sentence, listen-and-type (dictation), word order, pick the picture, root → derive the word with a pattern (فاعل، مفعول، مفعل …). Varied retrieval beats one card type | ★★★   | 8      | new           |
| **Sentence-first cards**: every word also appears in 1–2 example sentences; reviews alternate between isolated word and word-in-context                                                                             | ★★★   | 5      | needs content |
| **Pattern trainer (أوزان)**: generate forms from root + pattern (e.g. كتب → كاتب، مكتوب، مكتب، كتاب) — Arabic morphology as a system, not a list                                                                    | ★★★   | 8      | new           |
| **Error notebook**: every wrong answer lands in "my mistakes" with the correct form and a short why; weekly mini-test from it                                                                                       | ★★★   | 3      | new           |
| **FSRS scheduling** with per-learner parameters                                                                                                                                                                     | ★★    | 5      | planned (P7)  |
| **Listening first**: audio-only review mode for commuting (hands-free: listen, answer aloud, self-rate)                                                                                                             | ★★    | 5      | new           |
| **Pronunciation feedback** at letter level (ع ح ق ص ض ط ظ, vowel length, shadda)                                                                                                                                    | ★★★   | 13     | planned (P7)  |
| **Grammar in small steps**: one rule, three examples, five drills, then spaced repetition of the rule itself                                                                                                        | ★★★   | 5      | needs content |
| **Pre-test / post-test per unit** to show real progress (and give the teacher data)                                                                                                                                 | ★★    | 3      | new           |
| **Tashkīl fading**: vowel marks disappear gradually per learner as reading gets secure (extends today's tashkīl levels)                                                                                             | ★★    | 3      | new           |
| **Handwriting**: trace and write letters with finger/stylus, stroke order check                                                                                                                                     | ★★    | 8      | new           |
| **Arabic keyboard trainer**: learn the layout with the unit's words                                                                                                                                                 | ★     | 3      | new           |

## 2. The learner space ("my Suffa")

| Idea                                                                                                                                                                 | Value | Effort | Note          |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- | ------ | ------------- |
| **Notebook**: own notes per word, unit and recording; highlight sentences while reading; everything searchable and offline                                           | ★★★   | 5      | new           |
| **My decks**: collect words from reading, videos and recordings into own lists ("sentence mining": tap a word in a transcript → it becomes a card with the sentence) | ★★★   | 5      | new           |
| **Arabic journal**: write 3–5 sentences a day; AI corrects gently, the teacher sees highlights; builds a portfolio over time                                         | ★★★   | 8      | new (P4)      |
| **Voice diary**: record one sentence a day; compare with a month ago                                                                                                 | ★★    | 3      | new           |
| **Role-play with al-Muʿallim**: at the market, at the doctor, introducing yourself — using only the vocabulary of units already learned                              | ★★★   | —      | planned (P4)  |
| **Graded reader shelf**: short texts per level with tap-to-gloss, audio and 3 comprehension questions                                                                | ★★★   | 5      | needs content |
| **Can-do portfolio**: "I can introduce myself", "I can ask for directions" — learner ticks, teacher confirms; shows progress beyond points                           | ★★    | 3      | new           |
| **Study plan**: pick days and minutes per week; Suffa plans reviews and new units, reminders follow the plan                                                         | ★★    | 5      | new           |
| **Weekly recap** with the words learned, time spent and the hardest word                                                                                             | ★★    | —      | planned (P2)  |
| **Offline packs** per unit with audio, for travel and weak connections                                                                                               | ★★    | —      | planned       |

## 4. Recommendation

For the pilot (by Jan 4), in this order — they need little platform work and multiply the
value of the content being added (content plan):

1. **Error notebook** (3) and **sentence-first cards** (5): biggest learning effect per point.
2. **More exercise types**: cloze + dictation first (5 of the 8).
3. **Notebook + my decks** (5 + 5): gives learners a space that is theirs.
4. **Live class mode** (8): makes Suffa part of the lesson itself — a strong reason for the
   teacher and the class to use it every week.

After the pilot starts: pattern trainer, journal (with P4), graded readers, can-do portfolio.
Everything else goes to the backlog and is prioritised with pilot data (engagement plan §8).

Questions for the teacher: which of these would he use in class? Which units does the class
work on from January? Would he let an older student help as content editor?
